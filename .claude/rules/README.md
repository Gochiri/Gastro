# Reglas del proyecto

`common/`, `typescript/` y `react/` provienen del proyecto ECC
(https://github.com/affaan-m/ECC, MIT), copiadas tal cual como convenciones de
código.

Deliberadamente **no** se copió el `CLAUDE.md` ni `rules/node.md` de ECC: esos
describen cómo trabajar sobre el propio repositorio de ECC (CommonJS, sin
TypeScript, `node tests/run-all.js`), que es lo contrario de este stack.
